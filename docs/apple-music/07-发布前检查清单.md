# 07 · 发布前检查清单

> 一句话摘要：把「能发」变成「发得对」——每一项都给出可执行的命令或可核对的位置，跑完一遍再点 Release。

---

## 0. 一次性准备

```bash
# 约定变量（PowerShell / Git Bash 均可，自行替换）
UPSTREAM_COMMIT=<上游提交号>
VERSION=v0.7.20-apple.1
```

---

## 1. 密钥与隐私（最优先，必须做）

- [ ] **全历史**扫描（不只看当前文件）：

```bash
# 方案 A：gitleaks（推荐，扫描 git 历史）
gitleaks detect --source . --report-path leaks.json --verbose
# 无输出/无泄漏即通过；有命中逐条人工确认
```

```bash
# 方案 B：无工具时的兜底（只看当前树，覆盖不到历史，不推荐单独使用）
git grep -nE "(api[_-]?key|secret|token|password|passwd|bearer)" -- ':!*.lock' ':!package-lock.json' | head -50
```

- [ ] 确认以下内容**不存在**于仓库与发布产物中：真实 Cookie、`Authorization` 头、账号邮箱、`localStorage` 导出、真实设备路径、内网 IP/域名、个人截图。
- [ ] 检查 `test/manual/` 与 `docs/` 下的脚本与图片：手动联调脚本只保留代码，不保留运行产物。
- [ ] 检查 `package.json` 新增脚本是否硬编码了只在本机存在的路径。
- [ ] 检查 `.env*`、`*.pem`、`*.key` 是否被误提交：`git ls-files | grep -Ei '\.(pem|key)$|^\.env'`。

---

## 2. 许可证与致谢

- [ ] 仓库根 `LICENSE` 为上游原文，未被替换或追加限制条款
- [ ] `package.json` 的 `license` 仍为 `AGPL-3.0`
- [ ] README 顶部三段声明齐全：基于上游 + 致谢、非官方、与 Apple 无关联
- [ ] `NOTICE` 的版本号与上游基底提交号已更新
- [ ] Release Notes 含「本版修改内容」与「许可证」两段
- [ ] Release 页面可到达对应源码（标签链接或源码包）
- [ ] 新增依赖的许可证已确认（如 `ws` = MIT），并在 `CHANGELOG.md` 记录版本

---

## 3. 版本号与仓库状态

- [ ] `git status --porcelain` 为空（无未提交改动）
- [ ] 当前分支为功能分支（如 `apple`），不是 `main`
- [ ] 标签命名符合约定：本次 `v0.7.20-apple.1`，后续按 `v0.7.20-apple.N` 递增
- [ ] `git describe --tags` 指向预期提交
- [ ] 不要依赖 `package.json` 的 `version` 判断该发什么版本（上游在两次发版之间不变）
- [ ] `git fsck --no-progress` 无错误

## 4. 可复现构建

- [ ] 干净目录可构建：

```bash
rm -rf node_modules dist release
npm ci
npm run typecheck
npm run test:unit
ELECTRON_DEV=false ELECTRON=true vite build
```

- [ ] 打包（记录实际使用的参数，写进 Release Notes）：

```bash
npx electron-builder --dir --win \
  -c.electronDist=node_modules/electron/dist \
  -c.win.signAndEditExecutable=false
```

- [ ] 产物体积与结构正常：`release/win-unpacked/resources/app.asar` 存在，`dist/index.html` 在 asar 内
- [ ] 产物的 `app.asar` 未被手工修改后重新签名（会破坏完整性校验导致启动失败）

---

## 5. 产物验收（在干净环境跑一遍）

- [ ] 把产物放到**纯 ASCII 路径**下启动（含中文路径可能直接退出，属已知限制）
- [ ] 首次启动无「多个实例」锁冲突：默认用户目录可用（若被占用，用独立用户目录参数验证）
- [ ] 主界面可加载：`file:///<构建路径>/resources/app.asar/dist/index.html`
- [ ] 未登录时点 Apple → 出现中文登录引导卡，**不**出现其他平台的扫码弹窗
- [ ] 登录后：资料库/搜索/专辑/歌单可出数据；专辑卡片显示歌手名而非「未知歌手」
- [ ] 播放单曲：出声来自 Apple（非 Folia 解码），Folia 底栏进度跟随
- [ ] 播放歌单（≥100 首）：能出声；记录从点击到出声的耗时（写进 Release Notes 的已知问题）
- [ ] 切歌/上一首/下一首/暂停恢复正常
- [ ] 随机与循环三态与 Apple 侧一致（Apple 侧改动后 Folia 会回读）
- [ ] 关闭 Folia：播控服务进程随之退出（无残留 `node`/`bridge` 进程）
- [ ] 专用浏览器：播放时**不**抢到最前；隐藏/最小化后播放不中断
- [ ] 播放 10 分钟后查看专用浏览器 profile 目录大小（应基本稳定，不持续膨胀）

---

## 6. 文档一致性

- [ ] `README` 的「已知问题」与本文档第 5 节的实测结果一致（尤其耗时数字）
- [ ] `CHANGELOG.md` 每条都有动机，不只列功能名
- [ ] `TECH_NOTES.md` 的架构图与实际文件对应（新增文件都出现在图里）
- [ ] `INDEX.md` 链接全部可达（本地校验：`grep -o '(\./[^)]*)' *.md` 逐个打开）
- [ ] 文档中无真实路径/IP/账号（与第 1 节重复检查一次）
