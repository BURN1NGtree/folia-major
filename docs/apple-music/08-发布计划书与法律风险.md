## 1. 上游关系处理（先做人，再做事）

### 1.1 法律上必须做的

AGPL-3.0 给的是**著作权许可**，不含商标许可，也不含"代表上游发言"的授权。所以：

- 必须保留上游全部版权声明（`LICENSE`、文件头注释、`package.json` 的 `license` 字段）。
- 必须明确标注"本仓库基于 `https://github.com/chthollyphile/folia-major` 修改"，并写明**基线提交**（`103be0af`，即上游 v0.7.20 之后 15 个提交）。
- 必须注明**修改日期**与**修改内容摘要**（AGPL §5(a) 要求 modified version 携带显著变更说明）。
- 整包（含你的改动）继续以 **AGPL-3.0** 分发，**不得**加任何额外限制（不得加"禁止商用""禁止再分发"之类条款）。

### 1.2 人情上强烈建议做的

- 公开发布**之前**，先给上游开一个 Issue/Discussion（或邮件），说明：你想做一个 Apple Music 接入的衍生版，会遵守 AGPL、标注来源、不冒用官方名义，问对方是否介意。
- 对方若表示"不希望出现衍生版"：法律上 AGPL 允许你继续分发，但**强烈建议改走"个人使用 + 不公开发布"**，或至少把项目改名、去掉一切可能被误认为官方的东西，并在 README 里明确"本项目与上游无任何关联，作者未参与"。
- 对方若提出具体条件（比如要求你在 README 顶部写明"上游不支持此类修改"），照做，并把对话记录留档。
- 上游的 `NOTICE`/致谢名单、赞助信息：原样保留，不要删。

### 1.3 表述红线

| 不能写 | 应该写 |
| --- | --- |
| "Folia 官方 Apple Music 版" | "基于 Folia 的非官方 Apple Music 衍生版" |

## 3. Apple 相关风险（这是本项目最大的雷区，必须写清楚）

### 3.1 技术事实（用于写免责声明，别夸大也别隐瞒）

- 程序**不解密、不下载、不转存**任何音频；播放由用户自己登录的 Apple Music **官方网页播放器**完成（Chromium 里跑 `music.apple.com`）。
- 程序通过浏览器调试协议（CDP）**控制这个官方页面**（建队列、播放、读当前曲目），并把状态回灌到 Folia 界面。
- 登录由用户在官方页面里手动完成；程序**不读取、不保存**账号密码，但会用到该页面的会话 Cookie（存于本机专用浏览器配置目录）。
- 因此：**能否播放取决于用户自己的 Apple Music 订阅与地区**；没有订阅、地区不支持、账号被限制，都播不了，这不是 bug。

### 3.2 条款风险（必须向下载者明示）

- Apple Media Services 条款通常禁止**自动化访问/脚本控制**其服务，也禁止规避地区限制、绕过付费墙。用 CDP 驱动网页可能被认定为"自动化访问"，存在**账号被限制或封禁**的风险。
- 本项目**没有**绕过 DRM、没有破解付费内容；但"是否属于被禁止的自动化"由 Apple 单方解释，作者无法保证你的账号安全。
- 不提供任何 Apple 账号、订阅、地区切换方法；不提供任何"解锁"功能。
- 若 Apple 发来投诉：第一时间下架相关 Release 与功能说明，保留沟通记录，不要对抗。

### 3.3 商标与素材

- 可以在文字里**描述性使用**"Apple Music"（说明兼容对象），例如"用于接入 Apple Music 网页播放器"。
- 不要在程序图标、启动图、仓库 banner 里使用 Apple logo / Apple Music logo / "Music" 音符图标；不要用 Apple 的宣传图做截图封面。
- 界面里如需显示平台名，用纯文字 + 自己画的通用图标（Folia 现有实现就是用字母/色块，保持即可）。

### 3.4 地区与合规

- 中国大陆：软件本身不涉及内容分发；但**不得**在文档里教用户绕过地区限制、共享账号、代充订阅。
- 若未来上架国内分发平台，需另做备案与内容合规评估——当前不建议上架任何应用商店。

## 4. 用户数据与隐私（下载者最关心）

必须在 README 里用一段人话说明：

1. **数据只落在本机**：配置在 `%APPDATA%\Folia`；Apple 登录态在本机专用浏览器配置目录（`%LOCALAPPDATA%\FoliaAMProfile`），或（若用 `--user-data-dir` 启动）在程序目录的 `UserData` 里。
2. **不上传**：程序不把 Cookie、账号、听歌记录发往任何第三方服务器；除 Apple 官方页面本身与上游原有功能（如在线音乐平台的官方接口）外，没有自建后端。
3. **可彻底删除**：删掉上述目录即清除，不写注册表、不留系统服务。
4. **不要在这个程序里登录你不想被本机进程读取的账号**（例如工作邮箱），它就是一个普通桌面程序，权限与普通程序一致。

同时声明：本项目**不收集**遥测；若上游原有崩溃上报/更新检查存在，要如实说明它会访问哪些域名（当前是 GitHub releases 检查）。

## 6. 仓库与发布物结构（照抄即可）

```
folia-major-apple/               ← 新仓库（fork 上游后改名）
├─ LICENSE                       ← AGPL-3.0 原文（不要改）
├─ NOTICE                        ← 上游版权 + 你的修改声明 + 日期
├─ README.md                     ← 顶部三行声明（见 §8 模板）
├─ CHANGELOG.md                  ← 每条改动 + 动机
├─ SECURITY.md                   ← 安全问题怎么报、不承诺修复时限
├─ DISCLAIMER.md                 ← 完整免责声明（中英双语，见 §8）
├─ docs/                         ← 本素材包 00-07 文档
└─ releases/                     ← 每个 tag 对应：源码 tarball + 绿色版 rar + SHA-256
```

**Release 页面必须挂**：

1. 绿色版 `Folia-prod.rar`（或 zip）
2. 对应源码 `folia-major-src.tar.gz`（AGPL §6）
3. `SHA-256SUMS.txt`
4. 构建方式一句话（`ELECTRON=true npx vite build` + 离线 electron-builder 命令）
5. 免责声明链接（指向 `DISCLAIMER.md`）

**不放进仓库的东西**：`dist/`、`release/`、`node_modules/`、`*.exe`、你的 `%APPDATA%` 备份、任何 Cookie/Token/测试抓包。`.gitignore` 参照 `01-仓库结构与-gitignore.md`。
