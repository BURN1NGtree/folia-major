## 4. 仓库首页可用简介（200 字内）

> **Folia · Apple Music 派**
> 本项目基于 `chthollyphile/folia-major`（https://github.com/chthollyphile/folia-major，AGPL-3.0）修改而来，感谢上游作者与贡献者。
> 它为上游接入了 Apple Music 网页端：可浏览与搜索 Apple Music 目录及个人资料库，播放由 Apple 网页实例完成，界面、队列、拼贴墙与歌词跟随状态同步；登录在独立浏览器中完成，不接触账号密码。
> 本项目为非官方衍生版本，与上游官方无关，与 Apple Inc. 无关联、未获其背书；仅驱动使用者自己的订阅会话，不进行解密或内容抓取。
> 本项目按 AGPL-3.0 分发，完整源码见本仓库；使用前请自行确认符合当地法律与 Apple 服务条款。

（约 190 字）

## 5. 建议的仓库文件布局

```text
<your-repo>/
├─ README.md                     ← 02-README 的正文
├─ CHANGELOG.md                  ← 建议按「功能点 + 动机」写
├─ TECH_NOTES.md                 ← 可直接用 03-改动原理 的正文
├─ NOTICE                        ← 05-法律与合规 的模板
├─ LICENSE                       ← 上游原文，不要改
├─ INDEX.md                      ← 本篇
└─ docs/
   ├─ release-form.md            ← 00
   ├─ repo-layout.md             ← 01
   ├─ tooling.md                 ← 04
   ├─ compliance.md              ← 05
   ├─ pr-guide.md                ← 06
   ├─ release-checklist.md       ← 07
   └─ screenshots/               ← 截图（待补）
```

> 说明：`02`、`03` 的内容本身就是给仓库根文件用的，其余篇目放 `docs/` 即可。README 里的链接请按此布局调整路径。
