## 一、这是什么

Folia 的一个**第三方修改版**，在原有音源（网易云、QQ、酷狗、酷我、波点）之外，新增了一路 **Apple Music** 音源：由你在自己的浏览器里登录 Apple 网页版，Folia 通过浏览器调试协议读取曲库/搜索/封面/歌词，并把播放指令翻译成网页版队列操作。

## 五、我们做了什么、没做什么（技术边界）

**做了**：

- 启动一个**专用浏览器实例**（独立 profile，与你的日常浏览器隔离）访问 Apple 网页版；
- 在**你已登录**的前提下，读取公开可见的曲库数据（歌单、专辑、搜索、歌词）；
- 把 Folia 的播放/暂停/切歌/队列映射为网页版操作。

**没做**：

- 不读取、不存储、不上传你的 Apple ID 密码；
- 不代填账号密码、不代替你完成双重验证；
- 不抓取、不保存、不分发音频流；
- 不回传任何数据到本项目服务器（本项目没有服务器）；
- 不修改 Apple 页面脚本以绕过其访问控制或计费。

## 六、隐私与本地数据

- 登录状态由 Apple 写入本机浏览器 profile，默认位置：`%LOCALAPPDATA%\FoliaAMProfile`（可在代码中改，但默认如此）；
- 该目录含 Cookies、Local Storage、IndexedDB、缓存等，**等同于你的浏览器登录态**，请按敏感数据处理；
- Folia 自身不读取其中的密码字段，但**该目录泄露等同于账号泄露**；
- 卸载/不再使用时的清理：关闭 Folia 后删除该目录即可（会需要重新登录）；
- 软件内既有的更新检查会访问 GitHub 获取版本信息，这与本版本无关，属上游原有行为。

## 十二、安装、校验与卸载

**安装（绿色免安装）**

1. 解压 `Folia-prod.rar` 到**纯英文路径**（如 `D:\Folia`，含中文或空格的路径可能导致启动失败）；
2. 双击 `Folia.exe`；
3. 设置 → 在线音乐平台 → Apple Music → 按引导登录（登录在专用浏览器窗口内完成）。

**校验**（建议下载后核对）

```
SHA-256 前 16 位：
f363a2d3113dc088  Folia-prod.rar
17f4379fd0284084  folia-major-src.tar.gz
5c59cd123aa80fd8  folia-major-changes.patch
```

**卸载**

1. 关闭 Folia；
2. 删除程序目录；
3. 视需要删除 `%APPDATA%\Folia`（应用数据）与 `%LOCALAPPDATA%\FoliaAMProfile`（Apple 登录态）。

## 十三、已知限制（不是没做完，是边界）

- 仅 Windows 实测通过，其他平台未验证；
- 依赖 Apple 网页版，Apple 改版即可能失效；
- 后台浏览器窗口位于屏幕外（不抢前台），切换登录时会短暂出现窗口；
- 首次播放/登录有 1–3 秒的实例升级耗时；
- 极少数情况下专用浏览器退出不干净，需手动结束进程或重启系统。
